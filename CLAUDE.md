# Claude — entrada al proyecto

Claude es el director de este proyecto (decisión del usuario, 2026-11-21).

- `AGENTS.md` es la **fuente única** de instrucciones del proyecto (cómo se instala,
  cómo se testea, estructura, convenciones, seguridad y reglas de trabajo). Léelo antes
  de tocar nada.
- `docs/HANDOFF.md` es el **registro de sesiones**: qué cambió, por qué, qué queda
  pendiente y cómo verificarlo. Actualízalo al terminar cada sesión de trabajo.
- Los cambios se entregan por commits y PRs; no hagas `git commit` ni `git push` sin
  permiso explícito del usuario.
